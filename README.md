# 🎮 PatchBot — Discord бот для отслеживания обновлений игр Dark_and_Darker и League of Legends (позже возможно будут добавлены еще игры)

**PatchBot** автоматически отслеживает новости о патчах, обновлениях и анонсах из официальных источников и отправляет уведомления в Discord-сервер.

## ✨ Возможности

- 🔄 Автоматический парсинг патчей из официальных источников
- 📢 Уведомления в реальном времени в Discord-каналы
- 🗄️ Хранение истории обновлений в PostgreSQL
- ⚙️ Гибкая настройка через админ-команды
- 🛡️ Поддержка прокси (Tor/VPN) без него в РФ не получится запустить :)

---

## ⚙️ Как работают автообновления
Администратор привязывает игру к каналу через /add_* команды

Бот автоматически проверяет обновления каждые N минут (настраивается в env)

При обнаружении нового патча/новости бот отправляет уведомление в привязанный канал

Команды /dark_and_darker_new, /league_of_legends_new, /project_zomboid_new позволяют проверить обновления вручную в любом канале

### 🎮 Dark and Darker
| Команда | Описание | Права |
|---------|----------|-------|
| `/add_darkanddarker` | Привязать Dark and Darker к каналу для автообновлений | Администратор |
| `/dark_and_darker_new` | Отправить последнее обновление Dark and Darker вручную | Все |

### 🎮 League of Legends

### 🎮 Project Zomboid

### 🔧 Общие команды
| Команда | Описание | Права |
|---------|----------|-------|

## 🚀 Быстрый старт

- Python 3.12+
- PostgreSQL

1. **Настройте окружение**
```bash
cp .env.template .env
```

2. **Запустите контейнер**
```bash
docker-compose up -d
```

# ⚠️ Важное примечание о прокси
Для работы бота на территории Российской Федерации может потребоваться использование прокси (из-за блокировок Discord API).

Что нужно знать:

Бот поддерживает прокси, но не включает их в этот проект

У вас должен быть уже настроен прокси-сервер (например, Xray, Shadowsocks, VPN с HTTP прокси)

В файле .env нужно указать ваш собственный адрес и порт прокси:
```bash
HTTP_PROXY=http://ваш_адрес:ваш_порт
HTTPS_PROXY=http://ваш_адрес:ваш_порт
PROXY_URL=http://ваш_адрес:ваш_порт
```

### Если прокси нет:
Бот не сможет подключиться к Discord API. Вы увидите ошибки вида ClientConnectorError или SSL handshake timeout
